# Solar-Powered-Remote-Water-Level-Relay
Solar-Powered Remote Water Level Relay
This project implements a solar-powered water level sensor system designed to

monitor reservoir or tank levels and wirelessly control a remote water pump

located 2km away. The sensor detects when the water reaches the halfway mark

and transmits a signal to the pump station. The pump is programmed to

automatically shut o if it does not receive a signal from the sensor for 10

seconds, ensuring reliable and autonomous operation.

The system utilizes a small solar panel to power the water level sensor, enabling

o-grid deployment. Wireless communication is established between the sensor

and the pump controller to cover the 2km distance. The project focuses on

ecient power management and robust signal transmission for remote water

management applications.
